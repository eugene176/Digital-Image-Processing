기하학처리(transformation)

화소처리가 단순하게 값에 추가하거나 뺴서 바꾸는 것
영역처리가 주위의 값을 이용해 값을 바꾸는 것
기하학처리는 픽셀값,주변 값들을 유지시킨 채 위치값만 바꾸는 것 = 매핑

매핑 = x,y의 값을 다른 위치로 옮기는 거(화소값 자체는 그대로)

x,y -> x_1 y_1
ㄴ이라고 할 떄 -> 이 화살표가 매핑(사상)의 개념 + 개입하는 시기

사상 종류

순(정)방향 사상 = forward mapping
원본 행렬 -> 목적행렬로 옮기는 방식
방식 : 주로 특정 숫자를 곱해서 목적 행렬 좌표를 구함(확대 기준 ,축소 기준이면 반대로 나눠줘야 함)

홀 : 확대할 때 선택받지 못한 좌표는 공백이 되는데 그 부분을 홀이라고 함
오버랩 : 선택(목표)되는 좌표가 겹치는 경우 

역방향 사상 = backsward mapping
목적행렬 -> 원본 행렬로 옮기는 방식
완성본인 목적행렬을 값들 중에서 원본 행렬이 알아서 가져감.
즉) 오버랩,홀은 해결가능(중복으로 못 가져가게 하면 되니깐)
방식 : 목적행렬 좌표에서 특정 숫자를 나눠서 원본 행렬 좌표를 구함(확대 기준, 축소 기준이면 반대로 곱해줘야 함)

빵구가 나는 게 홀
여러 픽셀 정보가 한 좌표에 몰려 마지막 픽셀 정보만 남아서 디테일이 꺠진 그림(원본이랑 다른 그림)이 생기는 게 오버랩

transformation 종류

평행 이동
움직이고 싶은 위치값에 x,y값을 더해줌
*좌표값만 바꾸는거지 뭐 크기,색을 바꾸는 건 X

코드할 떄 numpy로 만든 행렬은 (y,x)순인 거 헷갈리지 말기

코드: cv2.getAffineTransform(img,(x,y)쌍 3개의 좌표)
ㄴ3개의 좌표쌍을 받아서 어파인 변환 행렬 반환
*여기서 말하는 쌍은 기존 위치 + 이동해 배치되는 위치로 2개를 의미
cv2.wrapAffine(image,위의 코드 반환값 행렬, 나머지 인수들은 default)


크기변경(확대/축소)
확대 축소할 떄 보간과 매핑을 사용하는 거임

회전
움직이고 싶은 위치값만 바꿈(진짜 기울이기만 함)

(0,0)위치를 축으로 회전함
물체를 축으로 회전하고 싶을 떄는 그 물체의 중심을 (0,0)으로 옮겨줘야 함. 다 회전시키고 다시 이전 위치로 돌려줌
1.평행이동 (0,0)으로
2.회전
3.평행이동 제자리로
코드 : cv2.getRotationMatrix2D(center,섹터값(몇도 돌릴껀지),무슨 비율로 확대/축소할지)
	ㄴ어파인 변환 행렬 반환
cv2.wrapAffine(image,위의 코드 반환값 행렬, 나머지 인수들은 default)


보간
홀을 막기 위해서 뭔짓을 했을 떄 화질이 안 좋아지는 건 어쩔 수 없음 근데 그 화질 안 좋아지는 걸 최소로 하기 위해서 사상을 통해 이동한 좌표들 사이에 있는 홀(빈 좌표)에 정해진 좌표에 있는 화소값의 중간값을 넣어주는 걸 보간이라고 함
ㄴ같은 선상의 값들을 고려해줘야 함(x/y중 하나, 애매한 중간에 있으면 둘 다 고려해줘야함)
ex)
100 160  =>  100 120 140 160
160 220 =>   160 180 200 220


보간 종류

NN - 최근접 이웃 보간법 
역방향 사상에 유용함,화질이 별로
홀이 있는 좌표에는 할당받은 목적 행렬 좌표들의 값들중 가장 가까운 값을 가진 원본 행렬 좌표값을 넣음

코드: cv2.resize(image,size,0,0,cv2.INTER_NEARST)

bilinear interface - 양선형 보간법
x,y방향을 다 고려하는 것
이론상 : x,y축을 다 고려하여 4개의 좌표에 있는 화소값,거리값을 계산해서 넣을 값을 정함
실전 : 사이드에 있는 좌표를 y축을 기준으로 보간값을 넣어주고 중앙은 x축을 기준으로 보간값을 넣어줌
*보간값 : 양끝에 있는 좌표들 화소값을 기준으로 정한 중간값

장점 : 화질이 좋아짐
단점 : 계산이 복잡해짐

코드 : cv2.resize(image,size,0,0,cv2.INTER_LINEAR)
cv2.resize(적용할 이미지,원하는 사이즈,늘리고 싶은 비율,늘리고 싶은 비율,방식)
특정 원하는 사이즈가 있으면 2번쨰 인수에 값을 넣고
특정 원하는 비율이 있으면 3,4번쨰에 인수를 넣어주면 됌


TSR = 평행이동(T),확대 축소(S),회전(R) = affine transformation

affine transformation
원본의 그림(색상,모양)을 바꾸지 않고 위치만 바꾸는 것
즉) 각 좌표값끼리의 관계는 바뀌지 않음.

코드 : cv2.affine
방식 : 기존의 TSR의 수식에서 곱해주는 행렬의 차원을 1개 더 늘려줌
ex)
x => x  로 만들어서  TSR을 한번에 진행시킬 수 있게 됌. = affine
y => y
	1

개념 : 회전 + 이동 + 확대 축소 등등을 미리 다 행렬곱 시켜놓고 나온 결과물에 [x,y,1]행렬을 곱해주는 것


원근 투시(투영) 변환 = projective transformation (중요 X,그냥 존재유무만 알기)
개념: 사람을 기준으로 접근함
ex) 멀리가면 작아보이고 오른쪽에서 보면 각도가 틀어지고 등등을 고려하여 원근감(입체감)을 주는 것

원근법 : 2차원읜 그림을 관찰자가 보는 것 그대로 사물과의 거리를 반영하여 그림

cv2.getperspectiveTransform(image,(x,y) 4개의 쌍)
