배열들 중 원하는 값만 바꾸는 형식을 지금까지 배움(명도 - 흑백,컬러 -RGB 값이 배열에 들어가 있음)

배열에 컬러 채널 순서는 B - G -R 순임

BGR 방식의 장점 : 색깔의 조합을 직관적으로 이해하고 활용 가능

BGR 방식의 단점 : 색깔이 아닌 명도를 바꾸고 싶을 떄(밝기 조절) 어떻게 바꿀지가 애매함.(BGR 증가는 단순한 숫자를 보는 게 아니라 비율로 봐야 함
그래서 다 같은 수치만큼 올리더라도 증가한 비율이 달라서 명도가 아니라 색깔이 바뀜)
ㄴ우리 눈이 인식하는 정도가 다르다는 뜻

컬러 채널의 종류
비슷한 개념
RGB,HSI,LAB,YCrCb
다른 개념
CMY(K) = CYM

RGB :각각의 채널이 색상의 정도를 소유하고 있음

CYM(K) : cyon,yello,magenta,(black)라는 의미를 각각의 채널이 가지고 있음(청록색,노란색,보라색,검은색)
ㄴK가 있는 이유 : 검은색을 만들기 위해서는 CYM을 매번 쏟아서 색을 합쳐줘야 함 -비용 문제,예전에는 잉크가 너무 많이 쓰여서 종이가 젖기도 했음
ㄴㄴ이놈은 보통 프린터에서 활용


*다양한 색이 합쳐질수록 검정색을 띔

HSI : RGB 채널에서 밝기,채도까지 조절하고 싶어서 만들어진 채널 방식
hsi = hsv,hsb - 셋 다 동의어
- RGB를 Intenstly,Value,Bright값으로 다시 쪼갬
- 값을 변경하고 다시 RGB값으로 변경하고 저장해야 함, 이 과정을 건너뛰면 컴퓨터가 의도한대로 인식 안하고 지맘대로 값을 넣음

hsi = 색상 채도 명도/강도
hsv = 색상 채도 명도 
hsb = 색상 채도 밝기

색상 = 0~360까지의 값을 가짐,나중에 BRG값으로 전환 할떄는 /2를 해주면 됌 
*채도 = 색의 순수한 정도 0~ 100(빛이 얼마나 섞여있는지) 100일수록 밝음, 0일수록 어두움.
*명도 = 빛의 세기(밝고 어두움) 0~100





Lab : Lab 컬러 공간은 인간의 눈이 인지하는 방식을 바탕으로 만든 ‘시각적으로 균일한’ 색 체계이며 색깔 원판 모양으로 자른 
다이어그램이 존재하고 3차원 구(공) 모양의 입체 구조도 존재
-거리가 같고 높이가 같으면 색깔의 세기 자체는 공학적으로 같다고 표현함.

문제점(lab)
1. 애초에 내부 값을 계산하는 것 자체가 힘듦(곡선도 가능해서)
2. 공학적으로 같은 것과 인간이 느끼고 같은 거는 다름.(완벽하게 계산해서 차이를 줘도 인간이 둔감하게 느끼는 경우가 있음)

YCrCb
이런 문제점을 극복하기 위해  처음부터 실제 사람이 느끼는 걸로 기준으로 잡고 계산하자 = YCrCb

영역처리(회선)

회선 : 주변의 값을 연산,이용해 값을 구하고 그 값을 적용시키고 똑같은 과정을 바로 옆 칸에 가서 적용시키고 
이걸 반복하는 게 회선(행렬 한 개를 더 붙혀서 그 행렬과 행렬곱을 시켜서 보통 값을 구함)

회선할 떄 붙히는 배열을 마스크,필터,윈도우,커널이라는 표현을 붙힘
마스크의 크기는 주변의 값을 지정하는 것과 동일, 얼마나 크게 반영하고 고려할 꺼냐.
