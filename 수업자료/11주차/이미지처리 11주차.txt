why) 영상에서는 자기 주변 픽셀의 변화량을 기준으로 하는거고 기존 미분식은 한 없이 0에 접근한다는 걸 기준으로 잡아서.

수평마스크와 수직 마스크 구분 방법

ex)
1    1      1
0    0    0
-1 -1 -1
ㄴ 이러면 위 아래는 0이 되니깐 무시 즉 수직 방향의 엣지를 구하는 마스크가 됌

소벨 마스크
-프리윗 마스크의 단점을 해결하기 위해 고안된 마스크
 
좌우,상하의 가중치를 늘려 2,-2로 방향성으 알려주고 대각선의 값들에는 1,-1로 방향성을 알려줌

방법
1. 좌우,상하의 가중치를 늘린 마스크를 각각 하나씩(좌우,상하) 만들기
2. 합치기
ex)
-1   0  1
-2   0  2
-1  0 1 
상하 마스크(수직) = 좌우를 비교해서 수직의 엣지를 찾는다는 의미여서 수직 마스크.

마찬가지로 상하,좌우 더했을 떄 0이 나오는 부분은 방향성을 0으로 보고 더했을 떄 0이 아닌 방향의 엣지를 구하는 것
쉽게 생각해서 -1가 붙은 방향이 음수 식에 들어오고 양수 숫자가 오는 방향이 양수 식에 들어옴 = 방향성
실제 화소 행렬에 저 숫자들을 곱한 값들 끼리 뺴서 나온 값을 중앙에 넣는 것.(다른 모든 마스크들 동일하게 중앙에 들어감,
로버츠 마스크가 2x2로 표현될 경우에만 왼쪽 위 모서리에 값을 넣음)

모폴로지
열림 연산과 닫힘연산이 핵심

영상 객체들의 형태를 분석하고 처리함

침식연산
객체를 침식시키는 연산(크기를 축소시키는)
-객채의 크기 축소,배경 확장
-작은 크기의 객체도 제거됌(노이즈가 제거됌)

-객체의 가장자리 index를 알아야함, 그걸 알아차리기 위해선 자기 주변의(상하좌우) 값들이 배경이면 가장자리임.
마스크를 활용(가장자리를 찾는데 이용)
마스크의 행렬과 사진의 행렬과 곱하고 상하좌우 중 하나라도 0이면 그놈은 가장자리가 되는 형식임.(논리 연산자 and사용)
ㄴ즉 남는 놈들은 안쪽 내부에 있는 값들만 남음.

마스크가 미분 마스크와 달리 자기가 어디까지 가장자리를 볼 꺼냐에 따라 내용물이 달라짐.

팽창연산
객체를 확대시키는 연산
-객체의 크기확대, 배경 축소
-객체 내부의 빈공간도 채워짐.
-객체 원래는 떨어져 있는 객체였는데 객체끼리 이어질수도 있음

마스크의 행렬과 사진의 행렬과 곱하고 상하좌우 중 하나라도 1이면 그놈은 가장자리가 되는 형식임.(논리 연산자 or사용)
ㄴ이번엔 가장자리를 늘리는 거니깐 or로 만들어서 가장자리를 남기는 게 목적임


열림연산 = 침식 -> 팽창(1.침식,2. 팽창)
닫힘 연산 = 팽창 -> 침식(1.팽창,2.침식)

-둘 다 물체의 전체적인 크기와 모양은 달라지지 않음
-근데 세부적으로 보면 아예 복구가 불가능하게 되는 경우가 있음(팽창,침식 모두 해당)

열림(opening)
-배경의 노이즈 제거 가능
-물체의 겉면을 부드럽게 만들 수 있음
= 겉면은 복구 불가능하고 작은 범위 또한 복구도 불가능함

닫힘(closing)
-내부의 구멍을 메울 수 있음(= 내부에 있는 노이즈를 없앨 수 있다.)
- 떨어져있던 객체들을 붙힐 수 있음(연결할 수 있음)
= 내부를 채우고 서로 연결되버린 객체들은 복구가 불가능함.


ex) 지문인식,지문만 남기는 경우(closing,opening 2개 다 사용)
