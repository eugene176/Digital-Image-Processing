LUT 테이블(lookup table)
1.표를 하나 만들고
2. 첫 테이블에는 인덱스만 저장하다가 표가 완성된 뒤에는 표에 있는 인덱스에 접근해서 그 값을 테이블로 가져옴


1,2번 방법은 쓸 줄 알면 좋다. 3,4,5는 습관이 안되있으면 힘듦



화소 밝기 변환(그레이 스케일 = 흑백 영상)
흑 : 어두운 상태 = 빛을 쏘지 않은 상태
백 : 빛이 밝은 상태

0~255의 밝기를 각 값마다 따로따로 인식 시키는 방식도 있음
0~255의 밝기를 구간화시켜서 사용할 수도 있음
ex)10 20 30 40 50 <-0~10 = 10, 10~20 = 20,20~30 = 30 처럼 대응하는 구간을 만듦
ex) 0 1 2 3 4 5 6 7 ~~~ <- 구간을 나누지 않고 숫자 그대로의 밝기를 인식하는 방법


덧셈 뺄셈으로 계산하다보면 0~255 범위를 넘길 떄가 있음. 이럴 떄 출력하는 방식이 2가지가 있음

1.modulo(numpy에서는 이 방법)
나머지 연산을 통해서  조정
음수가 들어오는 경우 : 256-(음수 숫자) % 256 의 결과로 조정
양수로 최대치를 뚫은 경우 : 그냥 최대치뚫은 숫자 % 256

2.saturation(cv2에서는 이방법)
최대치를 넘으면 알아서 255로, 최소치를 넘어서 -구간으로 가면 0으로 조정

복잡한 모듈러를 쓰는 이유
saturation으로 돌려버리면 싸잡아서 다 0으로 만들어버리는 경우, 싸잡아서 다 255로 만들어버리는 경우가 발생해서 
굴곡이 보이지 않는 경우가 생김.(물체의 형태를 유지시키지 못함)
근데? 모듈러는 굴곡 유지, 물체의 형태를 유지시킬 수 있음.


블렌딩(값을 합치는/섞는 걸 의미)

ex)배경 + 물체 = synthesis라고도 부름

방법 1. 2개의 값을 합쳐서 평균 내는 것(잘 안씀)

방법 2. 한 이미지의 투명도와 선명도를 이용, 선명도 x 타 이미지 값 + 투명도 x 본인 이미지 값

방법 3. 자기 투명도/선명도 * 자기 이미지 + 자기 투명도/선명도 * 자기 이미지

히스토그램
화소값마다 반도수를 측정해  표(도수분포표)를 만들고 그걸로 그래프로 작성. 여기서도 구간을 쪼갤 수 있음.

1. 인덱스를 값으로 인지하고 그 값에 횟수(갯수)를 넣기.
2. 그래프 그리기.


방법 1. 히스토그램이 좁을 떄 - histogram-stretching(데이터를 x축 방향으로 늘어뜨림)
ex) 분포가 100~150에 분포되있을 때 강제로 범위를 0~255로 있는 걸로 쳐서 
데이터 최소값을 0에 맞추고 최대값을 255에 맞추면서 늘어뜨림.

최소를 0으로 맞추고 나머지는 기존 최소값의 격차만큼 0에서 +해준 값으로 위치시키게 하고 
(늘어뜨린 최대값-기존 최대값)/늘어뜨린 최대값 곱해주기(모든 데이터에 적용)

방법 2. 히스토그램의 분포는 넓은데 데이터가 한쪽으로 치우쳐져 있을 떄
-이미 분포 범위가 0~255라면, 이미 데이터가 한쪽으로 몰려있는 경우.(최소,최대를 더 이상 늘릴 수 없을 떄) 스트레칭 이용 불가
ㄴ해결 방법이 평활화(equalizer)
1.누적빈도수를 계산
2.정규화 누적합를 구하기 = 누적빈도수/전체 데이터 수
3.누적합 * 최대값을 한 뒤 그 결과를 보고 등수 정하기

cv2.equalizeHist(이미지)
ㄴ 이건 사용자 정의는 스킵했음
